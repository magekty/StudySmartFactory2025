1. 프로젝트 기획 및 설계 개요
1-1. 기획 단계
목표 정의
가족 건강과 생활 밀착형 날씨 기반 ‘행동 유도 + 맞춤 알림’ 솔루션 개발

주요 기능 목록

피부 건강 보호(자외선 지수 기반 선크림 권장)

어린이·노약자 외출 경고(폭염, 미세먼지 등 상황별)

환기 타이밍 알림(실외 대기질 상태 기반)

산책 추천 지수(기온, 강수확률 등 종합)

일사병·열사병 주의 경고(위치기반)

가족별 맞춤 알림 설정(연령, 건강 상태 기반)

기술 스택 선정
React 기반, 상태관리(React Context or Redux), 스타일링(MUI, styled-components 추천)
TypeScript 적용 권장하나, 빠른 개발 우선 시 JavaScript 가능

팀 역할 분배
(팀 상황에 따라) 프론트엔드, 백엔드, UI/UX 담당 분리 계획

1-2. 설계 단계
화면 설계 (와이어프레임)

메인 대시보드: 차트로 주요 지표 시각화

상세 알림 페이지: 행동 유도 알림과 리마인더 관리

라우팅 구조
/ → 메인 대시보드
/alerts → 상세 알림 및 맞춤 설정 페이지

컴포넌트 구조
공통: Header, Footer, Notification, Chart 컴포넌트
페이지별: DashboardPage, AlertPage 등

데이터 흐름 설계
API 호출 → 상태관리 → 컴포넌트 렌더링
사용자 프로필 및 알림 설정은 로컬 상태 또는 서버 연동

API 명세
RESTful 방식 권장
응답 예:

json
복사
편집
{
  "uvIndex": 7,
  "pm10": 45,
  "pm25": 30,
  "temperature": 28,
  "alerts": [
    {"type":"uv", "message":"SPF 50 이상 바르세요", "level":"high"},
    ...
  ]
}
2. MVP 및 핵심 기능 요약
2-1. MVP 우선순위 및 범위
순위	기능	설명	API 활용	우선순위 이유
1	행동 유도형 알림(자외선 & 미세먼지 중심)	즉시 행동 가능한 메시지 제공	생활지수 API(UV지수), 대기질 API(PM10, PM2.5)	사용자 체감 및 건강 보호 직접 영향
2	가족별 맞춤 알림 관리	연령별 맞춤 알림 및 프로필 관리	사용자 입력 기반	가족 단위 충성도 증대
3	환기 타이밍 알림	실외 공기질 상태 고려 환기 권장	대기질 API	생활 편의 직접 개선
4	일사병·열사병 주의 경고	고온·강한 자외선 위치 기반 경고	생활지수 API, 단기예보 API	건강 사고 예방
5	산책 추천 지수	기상 조건 종합 산책 적합도 제시	단기예보 API	행동 유도 보조

MVP는 1, 2번 기능 중심으로 개발

3~5번은 차후 업데이트 예정

2-2. 핵심 기능 세부
행동 유도형 알림

“지금 SPF 50 이상 선크림 바르세요”

“미세먼지 낮음, 창문 여세요”

리마인더 기능 포함

가족 중심 개인화

어린이, 노약자, 성인별 맞춤 메시지 분리

건강 상태 반영 알림 최적화

2-3. 차별화 포인트
단순 날씨 정보가 아닌 즉시 행동 가능한 의사결정 지원형 알림

가족 단위 맞춤 관리로 사용자 충성도 및 건강 관리 효율 극대화

리마인더 및 상황별 맞춤화로 알림 피로도 최소화

3. API 활용 적합성 및 대응 전략
API명	활용 가능 기능	데이터 품질 및 한계	대응 방안
생활지수 API	UV 지수 기반 피부 건강 알림, 일사병 경고	자외선 지수 신뢰성 높으나 위치 정확도 중요	GPS 연계해 세밀한 위치 기반 알림 적용
대기질 API	미세먼지(PM10, PM2.5) 기반 환기, 외출 경고	측정소 간 데이터 편차 존재, 일부 지역 데이터 불균형	인근 측정소 데이터 가중평균 등 보정 적용
단기예보 API	기온, 강수확률 등 산책 추천, 열사병 주의	예보 변동성 존재, 실시간성 부족	실시간 관측 데이터와 조합해 알림 보정 적용

4. UI/UX 및 페이지 구성 제안
메인 페이지 (대시보드)
차트 중심 시각화:

자외선 지수 추이, 미세먼지 농도 변화, 환기 적합도, 산책 지수 등

실시간 데이터 반영, 사용자 위치 기반 정보 제공

직관적인 건강 상태 한눈에 확인 가능

2번째 페이지 (상세 알림 관리)
핵심 기능 ‘행동 유도형 알림’ 집중 제공

알림 내역 확인, 리마인더 설정, 가족별 맞춤 알림 수정 가능

사용자 프로필 및 환경 설정 연동

5. 기술 스택 최종 제안
구분	추천 기술	이유 및 설명
UI 라이브러리	React + MUI (Material-UI)	빠른 UI 개발, 접근성 및 반응형 디자인 지원
상태관리	React Context 또는 Redux Toolkit	중간 이상 규모 프로젝트에 안정적 상태 관리
API 호출	axios	Promise 기반 편리한 HTTP 통신 지원
라우팅	react-router-dom	SPA 내 페이지 네비게이션 구현
스타일링	styled-components / emotion	컴포넌트 단위 스타일 관리 및 재사용성 강화
타입스크립트	적용 권장 (팀 숙련도 고려)	코드 안정성, 유지보수성 향상, 협업 효율 증대
테스트	Jest + React Testing Library	단위 및 UI 테스트 지원
개발 도구	Vite	빠른 빌드 속도와 간편한 설정
버전관리	Git	협업 및 소스 관리 필수
