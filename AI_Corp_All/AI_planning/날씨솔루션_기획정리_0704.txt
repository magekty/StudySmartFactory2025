 기획 단계
목표 정의: 무엇을 만드는가 (ex. TODO 앱, 대시보드)

주요 기능 목록 작성: CRUD, 로그인, 필터 등

기술 스택 선정: React, Vite, 상태관리, 스타일링 방식 등

역할 분배 (팀일 경우): 프론트/백 구분, UI/로직 담당

1. 설계 단계
화면 설계 (와이어프레임) 작성
→ 사용자가 주요 UI/UX 아이디어 제시 및 AI가 와이어프레임 생성

라우팅 및 페이지 구조 확정
→ 페이지별 URL 및 주요 컴포넌트 배치 결정

컴포넌트 구조 설계
→ 재사용 가능한 컴포넌트 목록 작성 및 역할 분담(예: AI가 기본 컴포넌트 생성, 사용자가 조정)

데이터 흐름 및 상태관리 설계
→ props, context, Redux 중 결정 및 구현 범위 조율

API 명세서 확정
→ AI가 API 요청/응답 형식 제안, 사용자 검토 및 피드백 반영

2. 개발 준비
개발 환경 세팅
→ Vite + React + TypeScript 세팅 및 필수 라이브러리 설치

코드 스타일 가이드 설정
→ ESLint, Prettier 등 협업 룰 AI가 자동 설정

프로젝트 폴더 구조 구성
→ AI가 제안, 사용자 확인 후 최종화

Git 저장소 초기화 및 브랜치 전략 수립
→ AI가 커밋 메시지 템플릿, 브랜치 전략 추천

3. 기능 개발 단계
컴포넌트별 기능 구현
→ AI가 기본 컴포넌트 코드 작성, 사용자가 검토 및 수정

API 연동 및 상태관리 구현
→ AI가 axios 호출 코드 생성, 사용자 피드백 및 테스트

Mock 데이터 활용 테스트
→ AI가 모의 데이터 생성 및 테스트 지원

사용자 피드백 기반 UI/UX 개선
→ 사용자 요청에 따른 AI 코드 리팩토링

4. 테스트 및 디버깅
단위 테스트 및 통합 테스트 작성
→ AI가 Jest, React Testing Library 코드 생성, 사용자 검토

크로스 브라우징 및 반응형 테스트
→ 사용자 직접 확인, AI가 가이드 제공

버그 수정 및 콘솔 정리
→ AI가 오류 탐색 및 수정 방안 제안

5. 배포 준비 및 운영
환경 변수 및 빌드 설정
→ AI가 .env 구성 및 빌드 스크립트 작성 지원

배포 플랫폼 선정 및 배포 자동화
→ Netlify, Vercel 추천 및 자동 배포 설정 AI 지원

운영 중 모니터링 및 피드백 수집 방안 기획

6. 문서화 및 프로젝트 회고
README 작성
→ AI가 자동 생성, 사용자 수정 보완

API 문서 및 기능 명세 정리
→ AI가 문서 자동화 도구 활용 제안

프로젝트 회고 보고서 작성
→ 사용자 경험과 개선점 정리 지원

/////////////////////////////////////기획단계 구상 항목
1. 피부 건강 보호	자외선 지수(UVI)에 따라 피부 타입별 주의 알림 및 선크림 권장	기상청 생활지수 API
2. 어린이·노약자 외출 경고	폭염/한파/미세먼지 상황에 따라 외출 자제/대체 활동 추천	기온, 습도, PM10, PM2.5
3. 환기 타이밍 알림	실외 공기질 좋을 때만 환기 추천, 미세먼지/습도 고려	기상청 대기질 API
4. 산책 추천 지수	온도, 풍속, 강수확률, 습도 기준으로 산책 지수 제공	현재 날씨 + 예보
5. 일사병·열사병 주의	고온/강한 햇빛 조건 시 사용자 위치 기반 경고	기온, 자외선, 체감온도
6. 가족별 맞춤 설정	사용자 유형(어린이, 고령자, 성인 등)별 알림 설정 가능	사용자 입력 기반

///////////////////////////////////요약 정리 핵심 기능 항목
1. 알림 유형: 행동 유도 + 맥락 기반
단순 정보 전달이 아닌, 사용자가 즉시 행동할 수 있도록 돕는 ‘의사결정 지원형 알림’ 제공

예시:

“지금 SPF 50 이상 선크림 바르세요”

“미세먼지 낮음, 창문 여세요”

“일사병 위험, 물 꼭 챙기세요”

“산책하기 좋은 날씨입니다”

“어린이는 오늘 실내 놀이 권장”

사용자 프로필별 맞춤 메시지와 리마인더(재알림) 기능 포함

2. 가족 중심 개인화
가족 구성원별(어린이, 노약자, 성인 등)로 맞춤 알림 분리 및 관리

생활 패턴, 건강 상태(아토피, 호흡기 질환 등) 기반으로 알림 최적화

가족별 맞춤 행동 가이드 제공으로, 가족 모두의 건강과 안전 관리 지원

예:

“5세 아이는 자외선 주의, 실내 놀이 추천”

“75세 어머니는 폭염 외출 자제 권고”

////////////////////////////////차별화 가능성 분석
1. 기존 솔루션 대비 명확한 차별점
대부분 날씨 앱은 단순 정보 전달에 그치지만,
“웰클리”는 사용자가 바로 ‘행동’하도록 돕는 의사결정 지원형 알림을 제공합니다.

또, 가족 구성원별 맞춤 알림은 현재 시장에서 매우 부족한 기능으로,
단일 사용자 중심이 아닌 가족 단위 맞춤 건강 관리는 큰 장점입니다.

2. 사용자 경험(UX) 측면의 경쟁력
행동 유도형 알림은 사용자의 실제 건강·생활 습관 개선을 유도해 충성도를 높임

가족별 개인화는 사용자가 솔루션을 지속 사용할 이유를 제공

맞춤형 알림과 리마인더로 알림 피로도를 줄이면서 유용성 극대화

3. 시장 및 수요 측면
가족 건강과 개인 맞춤형 서비스에 대한 사회적 관심과 수요가 꾸준히 증가 중

특히 코로나 이후 건강 관리, 실내 공기질, 야외 활동 안전에 대한 니즈가 커짐

사용자들이 직접적인 ‘행동 가이드’를 받길 원하는 경향이 강함

4. 확장 가능성
기본 기능만으로도 시장 진입 가능하며,

추후 AI 기반 예측, 건강 데이터 연동, IoT 연동 등 고도화 확장 여지 큼

////////////////////////////// 프로젝트 핵심 요약
1. 주요 기능 구상
피부 건강 보호: 자외선 지수에 따른 피부 타입별 알림 및 선크림 권장

어린이·노약자 외출 경고: 폭염, 한파, 미세먼지 상황에 따른 외출 자제 및 대체 활동 안내

환기 타이밍 알림: 실외 공기질 상태 기반으로 적절한 환기 시점 알림

산책 추천 지수: 기온, 풍속, 강수확률 등 종합 지수로 산책 적합 시간 제안

일사병·열사병 주의: 고온 및 강한 자외선 상황에 사용자 위치별 경고 제공

가족별 맞춤 설정: 연령, 건강 상태 등 사용자 유형별 맞춤 알림 기능

2. 차별화된 핵심 기능
행동 유도형 알림: 단순 정보 제공에서 벗어나 “지금 행동하세요” 메시지로 사용자 실천 유도

가족 중심 개인화: 가족 구성원별 맞춤 알림과 행동 가이드 제공, 가족 모두의 건강 관리 지원

맞춤형 리마인더: 사용자별 상황에 맞는 재알림 기능으로 알림 효과 극대화

3. 경쟁력 및 시장성 분석
명확한 차별성: 기존 날씨 앱 대비 가족 단위 개인화와 행동 유도 알림에서 우위

UX 강점: 건강한 생활 습관 개선을 위한 지속적인 동기 부여와 알림 피로도 최소화

시장 성장 가능성: 개인 맞춤 및 가족 건강에 대한 사회적 관심 증가와 코로나 이후 수요 확대

확장성: AI 예측, 건강 데이터 연동, IoT 연동 등 차후 기능 추가 용이

4	일사병·열사병 주의 경고	고온, 자외선 강한 시기 위치기반 경고	건강 사고 예방 중요하나 빈도 낮음, 보조 기능	생활지수 API(UV지수), 단기예보 API(기온) 활용 가능
5	산책 추천 지수	기상조건 종합해 산책 적합도 제시	행동 유도형 보조 기능, 체감도 중간	단기예보 API(온도, 강수확률 등) 활용 가능

2. MVP 개발 범위 권고
1, 2번 기능을 우선 개발 MVP로 선정
→ ‘즉시 행동 유도형 가족 맞춤 알림’ 기능으로도 충분한 사용자 가치 제공

3~5번은 차기 버전으로 점진적 확장 가능

우선 API 데이터 품질, 알림 UX, 개인화 UI 집중 개발 필요

3. API 3가지 활용 적합성 분석
API 명칭	활용 가능 기능	데이터 품질 및 한계	대응 방안
생활지수 API	UV 지수 기반 피부 건강 알림, 일사병 경고	자외선 지수는 신뢰성 높으나 위치 정확도 확인 필요	GPS와 연계한 세밀한 위치 기반 알림 적용
대기질 API	미세먼지(PM10, PM2.5) 기반 환기, 외출 경고	일부 지역은 측정소 간 데이터 편차 존재	가중평균 또는 인근 측정소 데이터 융합
단기예보 API	기온, 강수확률 등 산책 추천, 열사병 주의	예보 변동성 있음, 단기 변화 반영 필요	실시간 데이터와 예보 조합해 알림 보정
