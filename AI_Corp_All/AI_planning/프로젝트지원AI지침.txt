[프로젝트 전체 지침 보고서] – 1부: 기획 개요 및 목적 정의
🔹 프로젝트 개요
프로젝트 명: 행동 유도형 날씨 알림 플랫폼 (가칭: "웰클리")

참여 인원: 2인 (사용자 1명 + AI 1명)

개발 방식: React 기반 단일 프론트엔드 프로젝트 (JavaScript 중심)

API 사용: 한국 기상청 공공데이터 API 3종 활용

🔹 개발 목표
기상 정보를 활용해 사용자에게 실제 행동을 유도하는 ‘맥락 기반 맞춤형 날씨 알림 솔루션’을 개발하는 것이 목표입니다. 단순한 날씨 정보 제공이 아닌, 사용자의 건강 및 생활 행동을 실시간으로 지원하는 지능형 경고 시스템 구축을 지향합니다.

🔹 기획한 주요 기능 (핵심 6가지)
#	기능명	설명	활용 API
1	피부 건강 보호	자외선 지수(UVI)에 따라 피부 타입별 주의 알림 및 선크림 권장	생활지수 API
2	어린이·노약자 외출 경고	폭염/한파/미세먼지 상황에 따라 외출 자제 및 대체 활동 추천	대기질 API
3	환기 타이밍 알림	실외 공기질 좋을 때만 환기 추천 (PM10, 습도 기준)	대기질 API
4	산책 추천 지수	기온, 강수확률, 풍속 등 조건 기반 산책 적합도 계산	단기예보 API
5	일사병·열사병 주의	고온 및 강한 자외선 조건에서 사용자 위치 기반 경고	생활지수 + 단기예보 API
6	가족별 맞춤 설정	연령/건강 상태(어린이, 노약자 등) 기반 맞춤 알림 제공	사용자 입력 기반

🔹 핵심 차별화 포인트
1. 행동 유도형 알림
“지금 SPF 50 이상 바르세요”

“미세먼지 낮음, 창문 여세요”

“물 꼭 챙기세요 – 일사병 주의”

즉각적이고 실천 가능한 메시지로 사용자의 행동을 유도함

2. 가족 중심 개인화
가족 구성원별(예: 아이, 부모님) 맞춤 알림 설정

생활 패턴과 건강 상태(예: 아토피, 폐 질환 등)에 따른 경고 메시지

리마인더 기능 포함

🔹 시장성 및 확장 가능성
경쟁력: 대부분 날씨 앱은 단순 정보 제공, 행동 유도 + 가족 중심 솔루션은 드묾

시장성: 건강 관심도 증가, 맞춤화 니즈 상승, 코로나 이후 공기질 인식 향상

확장성: 향후 AI 예측, IoT 연동(공기청정기), 웨어러블 데이터 연동 가능

🔹 API 연동 및 명세
사용 API 3가지
API 명	주요 활용	유의사항 및 대응
생활지수 API	UV 지수 기반 피부 보호, 열사병 경고	위치 정확도 보완 필요 (GPS 활용)
대기질 API	PM10, PM2.5 기반 외출/환기 판단	측정소 간 차이 → 평균/보정 필요
단기예보 API	기온, 강수 등 → 산책 추천, 열사병 예측	예보 데이터 변동성 존재

🔹 MVP 정의 및 우선순위
✅ MVP 최우선 기능 (1~2번)
순위	기능	이유	사용 API
1	행동 유도형 알림 (자외선, 미세먼지 중심)	사용자 체감도 가장 큼	생활지수, 대기질
2	가족 맞춤 알림 설정	개인화 + 반복 사용 유도	사용자 입력 기반

→ 이 두 기능만으로도 충분한 사용자 가치 제공 → MVP로 선정

✅ 차기 확장 기능 (3~5번)
환기 타이밍, 산책 추천, 열사병 경고 등은 차기 업데이트 대상
